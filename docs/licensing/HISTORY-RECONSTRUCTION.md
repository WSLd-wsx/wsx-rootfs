# History reconstruction after license activation

The owner approved active module grants before preparing a new root commit.
Preserve old refs, a verified Git bundle, current files and hashes externally in
a repository-exclusive backup. A bundle is not an attachment or LFS backup.
Show the exact old/new refs and tree differences before the concrete rewrite
confirmation. Recheck the remote old SHA, then use an explicit force lease.

The new root includes effective licenses; it does not revoke prior grants, alter
upstream rights or erase historical distribution facts. Provenance references to
older commits remain evidence in the preserved history. Public image clearance
is separate. New component packages must be built from the active-license tree;
record their actual pins through a later normal commit.
